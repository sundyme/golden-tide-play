# 零基础用 AI 做游戏：起步包

这是《金潮号 GOLDEN TIDE》项目整理出来的起步包。作者不会写代码，用 Claude Code（Claude Opus 5.5）做出了这款 3D 推币游戏。模板以 Claude 为例，换成 Codex 或其他 AI 编程智能体也能用。

▶ 试玩：https://sundyme.github.io/golden-tide-play/

## 里面有什么

| 文件 | 用途 |
|---|---|
| [01_模板合集.md](01_模板合集.md) | 从开工到发布，每一步可以直接复制给 Claude 的话 |
| [02_金潮号总提示词_原文.md](02_金潮号总提示词_原文.md) | 金潮号开工前写的 248 行项目总提示词，当作「一份完整方案长什么样」的参考 |
| [03_Codex画师守则_AGENTS.md](03_Codex画师守则_AGENTS.md) | 让 Codex 当画师时，放在项目根目录的守则文件模板 |
| [04_美术需求单模板.md](04_美术需求单模板.md) | Claude 给 Codex 派活时用的需求单格式 |

## 怎么用

1. 准备一个 AI 编程智能体：作者用的是 Claude 桌面版的 Code 标签页（需要付费订阅）；用不上 Claude，也可以用 Codex 或国内的 AI 编程智能体，效果会差一点，流程一样。打开后选一个新建的空文件夹。
2. 打开 `01_模板合集.md`，从「第 1 步」开始，把模板里【】的部分换成你自己的想法，发给 Claude。
3. 想参考一份成熟的方案，就把 `02_金潮号总提示词_原文.md` 发给 Claude，说：「参考这份的结构，给我的游戏写一份总提示词」。
4. 03 和 04 不用你自己填。接上 Codex 后，把它们交给 Claude，它会按你的项目改好。

> 总提示词里有一些只适用于作者电脑的路径（比如 Codex 的安装位置），Claude 会按你的电脑实际情况调整。

## 几条安全提醒

- 用一个单独的新文件夹，别让 AI 碰到你的私人文件。
- API 密钥不要贴进聊天框，让 AI 弹出输入框，存在本地，不进代码仓库。
- 给按量付费的服务（3D 生成、配音）设好预算，先少量试，满意再批量。
- 别用别人的角色、商标和知名 IP；字体、音乐、音效要确认可以免费使用或商用。
- 推币类游戏只图个乐，不要接入真钱充值或兑换。
